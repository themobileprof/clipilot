Install Clio

Do these steps from top to bottom. Commands under Terminal run in the shell. When a step says to quit, type exit before the next command.

Have these ready
  • A phone with Termux, or a Linux computer
  • A GitHub account
  • A DeepSeek API key and a Gemini API key. Step 4 creates them.
1

Open a terminal

Phone

Install Termux from F-Droid or the Termux releases. The Google Play copy is too old. Open it. You should see a $ prompt.

Computer

Open the terminal.

2

Install

Terminal

Terminal
curl -fsSL https://clipilot.themobileprof.com/clio | sh

If that fails:

Terminal
curl -sfL https://raw.githubusercontent.com/themobileprof/clio/main/install.sh | bash

Close the terminal and open it again. On a computer, if clio is still missing:

Terminal
export PATH="$HOME/.local/bin:$PATH"

Check: clio shows >>. Type exit.

3

Download the wizards

Terminal

Terminal
clio

At >> type sync, wait until it finishes, then exit.

On a phone, run each wizard in the shell after you type exit. Running one at >> can crash the app.

Check: run clio again. At the >> prompt, type setup. You should see a list that names Neovim and Git, each marked downloaded or not downloaded. Type exit to leave Clio.

4

Get the API keys

Do this in a browser before the wizards. Neovim asks for the DeepSeek key. Gemini is the free key from Google AI Studio. Keep both private. Do not save either key inside a site folder.

DeepSeek

Open platform.deepseek.com/api_keys, sign in, and create a key. Copy it. DeepSeek charges for use. Paste this key when Neovim setup asks. The typing is hidden, and the key is stored in ~/.config/gp/deepseek.key.

Gemini

Open aistudio.google.com/apikey, sign in, and create a key on a project with no billing account. New accounts can call some models, including gemini-3.8-flash, at no charge, within that project's limits. Google may use free-tier prompts to improve its products.

The $300 Google Cloud welcome credit does not pay for AI Studio or this API. A free Gemini plan for students is the Gemini app, and it does not create this key.

Check: you can see a DeepSeek key and a Gemini key, and neither is inside a folder you will push to GitHub.

5

Prepare the phone

Skip this step on a computer.

Terminal

Terminal
clio termux_setup

Say yes to storage and the shell. When it asks Build HTML pages?, say yes. Pico CSS is saved at ~/.clio/share/pico.classless.min.css. Say no to extra languages unless you want them. If it asks for a DeepSeek key, paste the one from step 4, or say no and save it later with clio key. If the shell switches to Zsh, open a new Termux session.

Ask a question from the terminal:

Terminal
clio ask 'your question'
clio key
6

Set up Neovim

Terminal

Terminal
clio neovim_setup

Paste the DeepSeek key from step 4 when asked. The typing is hidden. The key stays in ~/.config/gp/deepseek.key, outside any site, so it is not pushed to GitHub.

If plugin install fails, open Neovim with nvim, run :PlugInstall, wait, then :qa.

KeysAction
,gaGenerate after the cursor
,grRewrite the selection
:wSave
:qQuit

Press i to type. Press Esc to leave typing mode. On an HTML file, ,ga and ,gr add the Pico rules to the sentence you type.

Check: nvim --version prints a version.

7

Set up Git and GitHub

Terminal

Terminal
clio git_setup
gh auth login

Use your GitHub email in the wizard. For gh auth login, choose GitHub.com, HTTPS, and a web browser.

Check: gh auth status and git config --global user.name both print your details.
